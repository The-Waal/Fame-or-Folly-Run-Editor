# Fame or Folly Run Editor
An amazing html program to manipulate FoF run saves!

This program is activly being worked on and is pretty experimental! 

Just click "Insert Save" and put in your run file! 
Your run save can be found at "%userprofile%\appdata\locallow\GrandGamesStudio\FameOrFolly" and is called "run_save_P1_save1.json"

After this is done, many things can be changed! (The amount of silver, what season you're on, etc)

Once you are done, click "Export Save" and replace your run save
(Any manipulation should be done when the game is closed, or on the main menu)
